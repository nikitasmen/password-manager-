pwvault board setup

Installs the vault firmware on an ESP32 board with an SSD1306 screen. Firmware .

  1. Plug the board in over USB: into a computer (Chrome or Edge), or into an Android phone with a USB-OTG cable (Chrome).
  2. Press Install and pick the board's serial port.

    This browser can't reach USB serial ports. Use Chrome or Edge on a computer, or Chrome on Android. The page must be opened over https.

  3. When it restarts, the screen shows wifi setup and a QR code. Scan it with the phone's camera to join the board's hotspot; the setup page opens (or go to http://192.168.4.1). Pick your 2.4 GHz network and enter its password.
  4. The screen then shows the clock and the board's IP. Pair your devices: press BOOT on the board, then scan the code with the app (or use Devices → Add a device on the desktop).

Updating a board that already holds a vault: install normally, and never pick "erase". Installing writes only the firmware; the vault and paired devices stay. Erasing deletes them. A board first set up from a source build with an older firmware gets a new certificate from this installer, so every device must pair again; update it once from source to avoid that.

The board also opens the Wi-Fi setup by itself whenever it can't reach its saved network for 30 seconds after starting, e.g. after a move or a new router.
